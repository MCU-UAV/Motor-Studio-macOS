# Motor Studio 性能优化 · 2026-11-14

最终设置：数值面板目标 20 Hz（50 ms），曲线目标最多 20 Hz。后台采集按独立的总线目标频率运行，不由显示刷新率决定。此版在独立本地副本完成，仅使用模拟设备验证。

## 卡顿原因及修复

主要剩余开销出现在数值变化后的 SwiftUI 布局测量。采样显示 `GraphHost.flushTransactions → GeometryReaderLayout → StackLayout.sizeThatFits` 占用明显；视图更新追踪显示导航和控制面板的 body 并没有反复重建，但布局仍重新计算。

对照验证：固定文字尺寸、隔离历史滑块、单独移除外层 GeometryReader 均无改善，相关实验变更已撤回。有效修复是让 `LiveReadout` 在 AppKit 文字视图内部观察数据，并异步在 SwiftUI 更新过程之外建立观察关系；数值变化只重绘文字区域，不再把数值依赖注册到外层 SwiftUI 布局。保留字体、辅助功能文字值、单位切换，并对连续更新、数据源替换及视图销毁做了测试。静态面板仍由 SwiftUI 管理。

## 本机 CPU 对照

macOS 26.5.1 / Apple Silicon / Swift 6.3.3 / macOS SDK 26.5，Release；同一全屏概览界面、100 Hz 模拟采集。用进程累计 CPU 时间的 5 秒差值除以壁钟时间测量；100% 代表占满一个逻辑核心。下表包含采集和界面开销，不是单独绘图耗时，受系统负载影响。

| 条件 | 应用 CPU |
|---|---:|
| 修复前，数值 5 Hz、曲线暂停 | 21.32% |
| 修复后，数值 5 Hz、曲线暂停 | 6.77%、8.17% |
| 修复后，数值 5 Hz、两条曲线 20 Hz | 18.55%、16.94%、18.15% |
| 最终版，数值 20 Hz、曲线暂停 | 11.37%、11.16% |
| 最终版，数值 20 Hz、两条曲线 20 Hz | 21.56%、20.53%、19.94% |
| 最终版，隐藏窗口、后台采集继续 | 3.78% |

上述数值为本机短时观察，不代表长期或真实电机压力测试。5 Hz 对照用于定位原因；交付版已按要求改为 20 Hz。目标频率受主线程调度与采集快照等待影响，不保证硬实时。

## 绘图与数据存储优化

- 曲线始终只有一个在途请求，过时结果丢弃；相同记录版本和请求直接复用快照。
- 原始记录按电机存储。32 点块逐步合并为 min/max 摘要，长窗口走分层索引；不足 65,536 点的窗口直接处理。
- 缓存曲线路径、坐标映射后路径、网格、图例、格式化文字；游标二分查找，稳定自动纵轴刻度。
- 图表隐藏、最小化或完全滚出可视区域时不发起查询；窗口隐藏时暂停数值发布，后台采集和原始记录继续。
- 原始记录不降采样，CSV 导出保留期内全部记录。手动刷新直接获取记录存储中的最新时间，不依赖数值显示快照。

## 回归验证

- 原生数值观察：外层依赖隔离、连续三次更新、替换数据源、销毁后停止更新，全部通过。
- 主线程阻塞 700 ms，后台接收 70 帧；模拟停止约 0.17 ms。真实串口停止延迟未测。
- 16 个信号、两种单位、边界时间窗、记录过期和数组压缩后的索引结果，与原算法的极值及首尾时间一致；点数不超预算。
- 360,001 条合成记录（一小时、100 Hz、3 个 ID），3 曲线输出 1,800 点：一次查询约 3.96 ms。
- 同一组 120,000 条单电机记录、3 个信号、连续 10 次查询：原降采样算法 62.44 ms，索引查询 36.01 ms，约 1.73 倍。前者已获得筛选后数组，不含全局筛选成本。此前一次运行约 2.64 倍，结果随机器负载变化。
- 1000 Hz 目标本次约 517 帧/秒；桌面调度并非硬实时。吞吐作为测量结果报告，测试验证采集与停止正确，不强制固定吞吐门槛。
- 模拟采集、停止、故障清理、重启、指令更新、旧指令拒绝、CSV 行数、暂停及手动刷新测试通过。详见 `performance-test-results.txt`。
- 原生界面验证了 20 Hz 数值与双曲线、输出端/转子端单位切换、隐藏/恢复及停止。

## 使用与范围

解压 `Motor-Studio-Performance-arm64.zip` 后双击 `Motor Studio Performance.app`；打开演示开关 → 连接 → 开始通信。应用与原本地版并存，包标识为 `io.motorstudio.desktop.performance`，构建号 3。

源码包中执行 `cd macos && bash scripts/test-native-runtime.sh` 复现测试；`bash scripts/build-app.sh` 打包。本机只有 Command Line Tools，未运行依赖完整 Xcode 的 XCTest 协议套件。Intel、macOS 14/15、真实电机和 USB 适配器未实测；未执行真实一小时壁钟运行或 1000 Hz 一小时内存压力测试。
